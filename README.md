# BOP House

Kopie van bophouse.com met creatorprofielen die je zelf kunt bewerken.

## Creator of foto toevoegen
1. Open `index.html` en zoek bovenaan de lijst `CREATORS`.
2. **Extra foto:** zet de foto in de map `fotos/` en voeg hem toe aan `images`, bijv. `"fotos/joy-2.jpg"`.
3. **Nieuw profiel:** kopieer een creatorblok, plak het onderaan de lijst en vul de velden in.

Via GitHub Pages (Settings → Pages → branch `main`) staat de site online.
